# PlexonPanel

[![Build](https://github.com/ZpkDxGames/PlexonPanel/actions/workflows/build.yml/badge.svg)](https://github.com/ZpkDxGames/PlexonPanel/actions/workflows/build.yml)
[![Release](https://img.shields.io/github/v/release/ZpkDxGames/PlexonPanel)](https://github.com/ZpkDxGames/PlexonPanel/releases/latest)
[![License](https://img.shields.io/github/license/ZpkDxGames/PlexonPanel)](LICENSE)

PlexonPanel is a Paper plugin for monitoring and administering a Minecraft
server from a responsive web dashboard. It reports live server health, players,
plugins, redacted logs, and optional chat while keeping every remote action
disabled until the server operator enables it locally.

> **Project status:** `1.0.0-rc.2` implements the database-less relay protocol
> used by the private dashboard. Validate it on a disposable server before
> production use.

## Release design

The plugin opens one outbound signed WebSocket to the PlexonPanel Cloudflare
relay. The relay forwards current frames to paired browsers but does not store
telemetry, console, chat, or action history in an application database. Vercel
serves the UI, the browser keeps a bounded IndexedDB convenience cache, and the
Paper server keeps the authoritative rotating local action audit.

No Firebase project or Firebase credential is required. Never place a Firebase
Admin/service-account key in this plugin, browser code, Vercel, or a public
repository.

## Features

- CPU, memory, disk, JVM, TPS, tick-time, uptime, and player-count monitoring
- current player and installed-plugin information
- redacted warning/error capture and opt-in full-console streaming
- optional global-chat streaming and dashboard sending
- opt-in player, whitelist, ban, chat, and allowlisted console actions
- persistent server UUID plus Ed25519 identity and signed replay protection
- one-use, five-minute pairing code generated by the plugin
- reconnect-safe initial snapshots and idempotent remote-action handling
- Paper-local JSONL action audit with configurable retention
- optional PlexonChats global-channel adapter

## Installation

1. Download the JAR from the [latest release](https://github.com/ZpkDxGames/PlexonPanel/releases/latest).
2. Place it in the Paper server's `plugins/` directory.
3. Start the server once and review `plugins/PlexonPanel/config.yml`.
4. Enter the relay `wss://.../v1/agent` URL and pin its Ed25519 public key.
5. Set `gateway.enabled: true`, restart Paper, and run
   `/plexonpanel diagnostics`.
6. Enable only the streams and remote actions you actually intend to use.

The configuration keys retain the `gateway.*` name for protocol compatibility;
the production endpoint is the database-less Cloudflare relay. Plain `ws://`
is accepted only for loopback development.

## Commands

| Command | Purpose |
| --- | --- |
| `/plexonpanel status` | Show connection and feature status |
| `/plexonpanel pair` | Generate and register a one-use five-minute pairing code |
| `/plexonpanel unpair` | Revoke all dashboard devices for this server |
| `/plexonpanel rotate confirm` | Replace the local server identity deliberately |
| `/plexonpanel reload` | Reload and validate configuration |
| `/plexonpanel diagnostics` | Show safe connection diagnostics |

Commands require their matching `plexonpanel.*` permissions and default to
server operators.

## Pairing and reconnect

Each server keeps a persistent UUID and Ed25519 identity under
`plugins/PlexonPanel/identity/`. `/plexonpanel pair` creates the PIN locally,
sends it only over the authenticated signed socket, and displays it only after
the relay confirms registration. The plugin never persists the plaintext PIN.

The relay binds the random server UUID to the plugin public key. On reconnect,
the plugin repeats the nonce challenge and sends fresh server, system, player,
plugin, and bounded recent-console snapshots. The same browser device remains
authorized until its 30-day credential expires, site data is cleared, or an
operator runs `/plexonpanel unpair`.

## Building

```bash
./gradlew clean test javadoc :agent:jar
```

The installable file is written to
`agent/build/libs/PlexonPanel-1.0.0-rc.2.jar`. See
[development notes](docs/DEVELOPMENT.md) for protocol and release details.

## Privacy and security

Console output, chat, player data, and addresses may be sensitive. Review
[PRIVACY.md](PRIVACY.md) and the [security policy](.github/SECURITY.md) before
connecting a production server. The relay is TLS-protected and messages are
signed, but it processes live frames in memory; rc.2 is not end-to-end
encrypted.

Generated identities, pairing codes, local audit files, browser credentials,
and relay private keys must never be committed.
