# PlexonPanel 0.1.0

The first PlexonPanel agent milestone for Paper 26.2 and Java 25.

## Included

- CPU, RAM, disk, JVM, TPS, tick-time, player, and plugin telemetry.
- Redacted error detection plus opt-in console and chat streaming.
- Paper global chat and optional PlexonChats global-channel integration.
- Opt-in remote console, player, whitelist, ban, and chat actions.
- Persistent Ed25519 server identity, one-time pairing, signed messages, replay protection, bounded queues, and JSONL auditing.
- Unit tests, GitHub Actions verification, protocol documentation, and a local mock gateway.

## Assets

- `PlexonPanel-0.1.0.jar` — install this in the Paper server's `plugins/` directory.
- `PlexonPanel-0.1.0-release.zip` — source workspace plus the installable JAR.
- `SHA256SUMS.txt` — integrity hashes for both artifacts.

Remote capabilities remain disabled by default. Review `SECURITY.md`, `PRIVACY.md`, and the generated `config.yml` before connecting a hosted gateway.
